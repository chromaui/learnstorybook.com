Storybook은 React, React Native, Vue, Angular, Svelte를 비롯한 여러 프레임워크의 UI 개발을 돕는 강력한 도구입니다. 개발자 커뮤니티가 활발하고 애드온도 다양합니다. 이 튜토리얼에서는 Storybook으로 할 수 있는 일 중 일부만 살펴봤습니다. 프로젝트에 Storybook을 적용해보면 안정적인 UI를 얼마나 효율적으로 만들 수 있는지 느낄 수 있을 것입니다.

## 더 배워보기

더 자세히 공부하고 싶다면 다음 자료를 참고하세요.

- [**Storybook 공식 문서**](https://storybook.js.org/docs/get-started/install)에서 API 문서, 커뮤니티 링크, 애드온 목록을 확인할 수 있습니다.

- [**UI Testing Playbook**](https://storybook.js.org/blog/ui-testing-playbook/)은 Twilio, Adobe, Peloton, Shopify처럼 빠르게 개발하는 팀들이 사용하는 작업 흐름의 모범 사례를 소개합니다.

- [**시각적 테스트 핸드북**](https://storybook.js.org/tutorials/visual-testing-handbook/)은 Storybook으로 컴포넌트의 시각적 테스트를 진행하는 방법을 자세히 다룹니다. 31쪽 분량의 무료 전자책입니다.

- [**Storybook Discord 채널**](https://discord.gg/UUt2PJb)에서 다른 Storybook 사용자들과 질문과 도움을 주고받을 수 있습니다.

- [**Storybook 블로그**](https://storybook.js.org/blog/)에서 UI 개발에 도움이 되는 최신 릴리스와 기능을 살펴볼 수 있습니다.
